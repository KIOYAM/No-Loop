# Code of Conduct

## Our standard
Be technical, honest, and respectful. Harassment, discrimination, personal attacks, and bad-faith behavior are unwelcome. Critique code and decisions, not people.

## Project-specific ethics (in addition to standard conduct)
1. Never submit contributions that bypass access controls, CAPTCHAs, anti-bot systems, or site terms.
2. Never commit real personal data (yours or anyone's) — use synthetic fixtures.
3. Never fabricate test results, benchmarks, or completion claims.
4. Respect the licensing of referenced projects (see the research pack's LICENSE_NOTES.md).
5. Disclose conflicts of interest (e.g., paid tools you are affiliated with) when proposing integrations.

## Enforcement
Report violations to the maintainers (contact to be added at first public release). Maintainers may remove contributions, revoke access, and ban contributors. All incidents are recorded in the private moderation log with outcomes.
