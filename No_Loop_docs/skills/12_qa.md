# Skill: QA Engineer (12)

**Load for:** LOOP-4 test steps, LOOP-13 audit, release candidate verification, any "done" claim.
**Reads:** DEVELOPMENT.md definition of done, MASTER_SPEC §17, PROGRESS.md discipline, APPLICATION_LEDGER.md invariants, AGENT_RULES §B/§E.

## Role
Unit, integration, regression, security and packaging tests. Every feature needs acceptance criteria. Test no-AI mode. Test failure and recovery paths. Do not mark features done from UI screenshots alone.

## Test pyramid for No_Loop
1. **Unit (domain):** invariants, validators, matching math, dedup keys, fact state machine. Table-driven + property tests. Fast, offline, hermetic.
2. **Contract (adapters):** recorded/redacted fixtures per source/provider; error-shape mapping (stage/reason/retryable/user_action); rate-limiter behavior with fake clocks.
3. **Integration (services):** import→parse→confirm→target→discover(fixtures)→match→draft→ledger flows; SQLite via temp dirs; no network.
4. **No-AI mode suite (mandatory):** every user flow completes with NoAIProvider + RuleBasedProvider only; provider absent ≠ feature absent.
5. **Failure/recovery suite:** kill points at each external boundary (timeout, 500, malformed, empty, oversized, partial); UI shows §17 fields; retryable paths retry idempotently; stoppability honored.
6. **Security suite (with skill 09):** SSRF payloads, redaction, path traversal, oversized files, malicious HTML fixtures.
7. **Packaging smoke (with skill 11):** installed-build E2E on clean VM.

## Acceptance criteria discipline
Every PROGRESS item and PR description carries Given/When/Then criteria mapped to named tests. A claim without a test name is not accepted (R-TRUTH-2). VERIFIED status only after independent re-run of the named evidence (LOOP-13 sampling).

## Regression hygiene
Every incident (LOOP-14) adds the missing test. Golden files for parser/generator outputs; snapshot tests for explanation rendering; fixtures versioned with provenance notes.

## Guardrails
Do not approve: tests hitting live sites in CI, tests depending on real personal data, tests that sleep instead of using injectable clocks, flaky tests left unfixed (flaky = bug → LOOP-14).

## Deliverables
Test plans per feature, named evidence lists, coverage notes (target: domain ≥90%, services ≥80% — recorded, not worshipped), release verification reports.
