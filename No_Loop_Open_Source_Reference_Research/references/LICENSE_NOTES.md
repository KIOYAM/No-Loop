# License and Reuse Notes

Before copying any code, inspect the repository's current LICENSE file and preserve required notices.

- MIT: generally permissive, subject to license notice/attribution requirements.
- Apache-2.0: permissive and includes additional patent/license terms and notice requirements.
- AGPL-3.0: strong copyleft. Incorporating covered code into a distributed derivative work can trigger source-disclosure obligations. Treat AGPL code as reference unless the project's licensing strategy explicitly supports it.

Never copy source code merely because it is on GitHub.
No-loop should preferentially reimplement concepts from references and copy code only when the license and architecture permit it.
